# Security self-audit

Reviewer: implementation agent, 21 November 2026. Scope: ../launch-kit/checklists/security.md. This is self-review, not an independent penetration test.

| Checklist area                    | Status                                            | Evidence / limits                                                                                                                                                                                                                                                                                                                                                                                                  |
| --------------------------------- | ------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Route inventory / ownership       | PASS for current scope                            | /api/parse and POST /api/interest are deliberately public. DELETE /api/interest requires a random 256-bit removal capability; /api/cleanup requires a timing-safe bearer secret. No stored statements or history IDs exist. Missing-origin, foreign-origin, malformed code and unsigned cleanup tests pass. No family or admin roles exist.                                                                        |
| Input validation / SQL            | PASS                                              | Stream byte limits independently of Content-Length; 3 MB PDF magic check, 30 pages and 2,000 rows. Bank allowlist and email/consent checks. All user-data SQL uses parameters. Versioned initial migration applied. Runtime role has no superuser, create-role or create-db privileges. Recovery procedure documented, drill not completed.                                                                        |
| Secrets                           | PASS for tracked source/history after final scans | Local credentials are ignored and excluded from deployment archives. Only runtime DATABASE_URL and CRON_SECRET are intended for production hosting; owner credentials remain local. Preview does not receive production secrets. A broad working-directory scan also saw ignored local credential files, as expected; it is not evidence of a tracked leak.                                                        |
| Shared limits                     | PASS for implementation                           | Atomic Neon upserts; 15 concurrent increments verified with no lost updates. Global 20 parse / 10 interest / 10 removal requests per minute. IP headers are unused, so spoofing them cannot select another bucket. Database failure refuses work. Shared global limits can be exhausted by one attacker. PDF memory amplification remains bounded only by host limits and request duration, not solely file bytes. |
| Cookies / CSRF                    | PASS / N/A                                        | No auth cookie, sessions, redirect input or CORS access. Mutations require canonical same-origin requests. No cookie expiry, role changes, payment webhook or replay handler exists because those capabilities are not implemented. Removal codes are hashed at rest; bearer possession permits deletion only.                                                                                                     |
| Headers                           | PASS on HTTPS                                     | Nonce CSP, nosniff, referrer policy, no framing/objects and restrictive permissions. Dynamic rendering supplies matching nonces. Shared header-check passed on the public HTTPS deployment, including HSTS.                                                                                                                                                                                                        |
| Dependencies                      | PASS at install                                   | npm audit returned zero findings; frozen reinstall and final audit recorded in validation evidence. Lockfile committed.                                                                                                                                                                                                                                                                                            |
| Gates and policy                  | PASS automated gates                              | Policies generated from the shared templates and actual current behaviour. Financial data is transient; interest deletion is tested. Daily expiry cron is implemented but cannot run on Vercel without its secret. Analytics component stays disabled.                                                                                                                                                             |
| Errors / recovery / accessibility | PASS for tested flows                             | Generic PDF and service errors; no raw stack traces sent. Server/client boundaries support retry. Desktop/mobile route tests show no horizontal page overflow. Controls are labelled. Full screen-reader and drag/drop audits are not claimed; tested upload uses the native file input.                                                                                                                           |

## Residual launch limits

Real-bank layout coverage is unverified. File parsing is untrusted computation on a hosting worker; Vercel maxDuration is 30 seconds, but this is not a separately hardened sandbox. No email verification, billing or saved history exists. Interest counts must not be reported as paying or verified users. Public promotion awaits real-statement validation and policy review. Do not present these smoke tests as a financial-data security certification.
